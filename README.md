# 肥鱼科研版 🐋

DeepSeek 二创形象「鲸鱼娘·大肥鱼」的透明桌面宠物 + AI 问答助手。

基于三视图素材（正面 / 侧面 / 背面），用 Python + PySide6 实现，无边框透明置顶窗口。

## 改动说明

### 界面：三个功能图标 + 一个投喂图标

单击肥鱼弹出 **4 个图标**（横向一排）：

| 图标 | 功能 |
|:---:|---|
| 🗨️ | AI 问答（完整聊天窗口，可滚动、可连续追问、历史持久化） |
| 🫧 | 天气查询（左键查天气，右键设置城市） |
| 💰 | DeepSeek 账户余额 |
| 🎁 | 投喂 |

信息类结果（天气 / 余额）显示在**独立的圆角气泡面板**里，不占用聊天窗口：
点击面板可在「简报 / 详情」之间切换，右键或按 Esc 关闭，鼠标移开一会儿自动收起。

### 天气查询：换成官方数据源

原版用 `wttr.in`（德国服务，国内城市数据粗糙、响应慢）。现改为多数据源自动降级：

| 优先级 | 数据源 | 实测响应 | 是否需要 Key |
|:---:|---|---|:---:|
| 1 | **中国天气网** `d1.weather.com.cn` | **~20 ms** | 否 |
| 2 | Open-Meteo | ~580 ms | 否 |
| 3 | wttr.in | ~1180 ms | 否 |

能查到：实时温度、风向风力、湿度、降水量、**空气质量 AQI**、**限行尾号**、
**7 日预报**、**天气预警**、**约 30 条生活指数**。

实现要点（都是踩过的坑）：
- 该接口返回 **GBK** 但 HTTP 头声明 utf-8，需要双重解码，否则城市名乱码
- 预报段 `var fc ={...}` **没有结尾分号**，且内部有嵌套对象，正则不可靠 → 用花括号配对提取
- 「今日高低温」两个字段会互相矛盾（缓存过时），按「谁和实时温度自洽就用谁」交叉校验
- 认不出的城市直接报错，不降级到 wttr.in（那个接口什么字符串都收，会返回看似正常实则错误的数据）

### 账户余额：新增

调用 DeepSeek 官方接口 `GET /user/balance`，显示余额、充值额、赠送额和查询时间。
（Token 用量统计**未做** —— DeepSeek 没有公开的用量查询接口，本地累计容易和官方账单对不上。）

### 台词系统：精简为两套，改成科研风

删掉了原版三套语录：

| 已删除 | 内容 |
|---|---|
| `LINES` | 13 条待机随机台词（含社区内部梗） |
| `REACT_LINES` | 7 条点击回嘴 |
| `INNER_LINES` | 8 条「内心吐槽」（含不适合课题组场合的内容） |

保留并重写为科研风：

- **拖动语录**（4 条）：`别拽我！离心机还在转呢！` / `样品洒了！这可是我跑了一周的样！` / `移送！移送！小心我的 EP 管！` / `我去开会了，跑胶的事回来再说……`
- **投喂语录**（4 图标 × 5 条）：
  - 🎂 实验成功 —— `Western Blot 显影成功！条带清晰，条条都是阳性！`
  - 🎀 论文相关 —— `文章接收了！可以毕业了！`
  - 🧪 实验操作 —— `p < 0.05，三颗星！有显著性！`
  - 💎 顶刊 / 大奖 —— `Paper accepted！！！可以毕业了！！！`

### AI 提示词：改成能认真回答问题的助手

原版人设要求「每句话不超过 25 字」，`max_tokens` 100，代码里还有 28 字截断 ——
三重截断叠加，问稍微复杂的问题只能得到半句话。

现改为：完整助手定位、`max_tokens` 1200、去掉代码截断，并要求：
- **不写能力声明 / 免责声明**（禁止「我没有联网能力」「我给不了准确答案」这类开场白，直接给答案或链接）
- 涉及专业内容时严谨作答，长度按需而定
- 天气类问题直接引导到 🫧 按钮，而不是凭记忆猜温度

### 修掉的 19 个 bug

详见 [`BUGFIXES.md`](BUGFIXES.md)，包括：线程安全的回复队列、配置键缺失导致的
启动崩溃、说话冷却、拖拽释放、精灵边缘白边、模型下载器清理等。

## 功能

- **三视图行走**：左右走用侧面（自动镜像）、向上走用背面、向下走用正面

- **三种模式**：自由散步 / 跟随鼠标 / 原地待着（右键菜单切换）

- **互动**：
  - 左键按住：拖拽（侧身朝向拖动方向，松手会说一句话）
  - 单击：蹦跳 + 弹出 4 图标功能面板
  - 双击：投喂面板（🎂 🎀 🧪 💎）
  - 右键：完整菜单（模式 / 大小 / 设置 Key / 显示隐藏 / 回到屏幕内 / 鼠标穿透 / 窗口置顶 / 开机自启 / 退出）

- **细节**：呼吸 / 摇摆 / 蹦跳 / 进食动画、转向交叉淡化、加减速惯性、散步自动休息

- 托盘图标、窗口置顶、鼠标穿透、开机自启、配置记忆（`config.json`）

- **系统状态监控**：CPU 超 90% / 内存超 95% / 显卡温度超 80°C 时冒泡提醒，间隔 10 秒

## 运行

需要 **Python 3.10+**（PySide6 6.11 使用 abi3，支持 3.10–3.14）

```bash
pip install -r requirements.txt
```

然后双击 `启动桌宠.bat`，或：

```bash
python 桌宠.py
```

首次使用 AI 问答需要在 **右键菜单 →「设置 Key」** 里填入
[DeepSeek API Key](https://platform.deepseek.com/)。天气查询不需要 Key。

---

## 打包成独立 exe

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name 肥鱼科研版 --add-data "sprites;sprites" --icon icon.ico 桌宠.py
```

产物在 `dist/肥鱼科研版.exe`，对方双击即用，无需安装 Python。
（杀毒软件可能对 PyInstaller 产物误报，加信任即可。）

## 更换形象

把新的三视图（白底）放到 `D:\图图\大肥鱼`，然后：

1. `python preprocess.py` —— 白底抠图 + 统一高度到 340px
2. `python preprocess2.py` —— 边缘去污 + 预乘 alpha 缩放出各档位精灵

程序按**高度**缩放、宽度自适应，三个档位对应的高度是 187 / 238 / 306 px。

> 注意：这两个脚本里的源路径是硬编码的，用之前先改成你自己的目录。
